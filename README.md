# 🎲 Jogo de Adivinhação em C++

Projeto desenvolvido em C++ com foco na prática de lógica de programação, manipulação de entrada e saída de dados, estruturas de controle e geração de números aleatórios.

## 🚀 Funcionalidades

* Geração de um número aleatório entre 1 e 100
* Sistema de tentativas
* Dicas indicando se o valor informado é maior ou menor que o número secreto
* Contagem de tentativas até o acerto
* Interface simples via terminal

## 🛠️ Tecnologias

* C++
* MSVC (Microsoft Visual C++)

## 📚 Conceitos Aplicados

* Variáveis e tipos de dados
* Estruturas condicionais
* Estruturas de repetição
* Bibliotecas padrão do C++
* Geração de números aleatórios
* Organização de código

## ▶️ Como Executar

### Compilar

```bash
cl /EHsc main.cpp
```

### Executar

```bash
main.exe
```

## 🎯 Objetivo

Este projeto faz parte da minha jornada de aprendizado em desenvolvimento de software e foi criado para reforçar conceitos fundamentais da linguagem C++, além de praticar boas práticas de organização e versionamento de código.
